# 🎯 Number Guessing Game in Python

A simple Python game where the computer generates a random number between 1 and 100, and the player tries to guess it.

## ✨ Features

- Random number generation using Python's `random` module
- Maximum of 7 attempts
- Hints for guesses that are too high or too low
- Input validation using `try-except`
- Game rules displayed at the beginning
- Functions for organized, reusable code

## 🛠️ Technologies Used

- Python 3
- Random module
- Exception handling
- Functions and loops

## ▶️ How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

```bash
python game.py
```

## 🎮 How to Play

1. Read the game rules.
2. Enter a number between 1 and 100.
3. Follow the hints: Too Low or Too High.
4. Guess the correct number within 7 valid attempts to win.

Invalid inputs and numbers outside the range do not count as attempts.
